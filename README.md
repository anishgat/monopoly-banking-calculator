## Step 4 
Type in the amount
Eg. 3M = $3,000,000

## Step 5
Press "+", "-", or "Rent"
The rent button allows you to handle interplayer transactions easily. Press rent to deduct from the first player, then select the second player, and simply press "+" to add the amount deducted from player 1 to player 2.
